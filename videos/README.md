# Videos

Put local test videos here (for example `videos/sample.mp4`). Video files are ignored by Git, so they are not uploaded to GitHub.

Supported extensions: `.mp4 .avi .mov .mkv .wmv .flv .webm .m4v`

Good test videos contain several people or vehicles (street, traffic, or a recording of your own room). Use only videos you own or that are licensed for reuse.

Run it with:

```
python main.py --video videos/sample.mp4
```
